# Airport Management System

A menu-driven C program to manage flights, passengers, ticket bookings and seats. It calculates fares using travel packages and age discounts, checks baggage weight, and saves all data in files with unique IDs.

## How to Run
Compile: `gcc airport.c -o airport`

Run: `./airport`

Login PIN: `320`

## Features
- PIN login (3 attempts)
- Flight and passenger management
- Travel packages and age-based discounts
- Ticket booking, seat allocation and cancellation
- Baggage weight limit and excess fee
- Search and revenue report
- File storage with unique IDs
